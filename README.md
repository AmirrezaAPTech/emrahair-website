# Emrahair — Bahçeşehir

Website for Emrah Çabkur's salon (Air Touch balyaj, renk, kesim). Built on the
Panfili site's architecture and section structure, rebranded and rewritten.
Turkish by default (`/`), English at `/en`.

```bash
npm install
npm run dev        # http://localhost:3000  (or: npm run dev -- -p 3030)
npm run build
npm run check      # tsc --noEmit
npm run media      # rebuild every video and still from media-src/
```

## Booking: how far the site goes

1. **Services** are chosen on the site (panel or price list). The selection is
   shared and kept in `sessionStorage`.
2. **Staff**: Emrah Çabkur, Serdar Sezer or "Fark etmez". Remembered and shown
   on the summary.
3. **Summary** with a price estimate, then **"Tarih & saat seç"** goes to
   Kolay Randevu with every service preselected:
   `randevu3.php?hizmetler[]=<id>&hizmetler[]=<id>&sube=137954`
4. Date, time and phone confirmation happen on Kolay Randevu.

Kolay Randevu does **not** accept the staff member in the URL (tested
`<id>-personel`, `personel`, `personel_id`, `calisan`; its staff pages link
back to the salon page). So the summary tells the guest exactly which option to
pick in "Personel Seçimi" (`Emrah ÇABKUR` / `Serdar Sezer`). Some services have
only one specialist on KR (Air Touch → Emrah, nails/brows/wax → Gizem) and KR
fills those in by itself.

## Data and where it came from (read 2026-11-04)

- `src/lib/services.ts`: every service, Kolay Randevu ID, price and staff,
  generated by `scripts/gen-services.py` from `scripts/kolayrandevu-services.json`.
- `src/lib/site.ts`: contact, hours, team, ratings, reviews (verbatim quotes
  from Google and Kolay Randevu).
- Brand colours were sampled from the salon's Google Maps photos and its
  storefront sign: gallery-white walls `#F4F3EF`, charcoal frames `#17181B`,
  caramel oak `#C9A27B` (the sign's brush stroke), burnt-orange feature wall
  `#A8461C` (buttons), teal arch `#4F7470`. See `src/styles/tokens.css`.
- Fonts: Bodoni Moda (display, replaces Panfili's Didot) and Hanken Grotesk,
  both open-licensed, self-hosted by `next/font`.
